# Datasets

## queue_synthetic.csv

**This is synthetic data, not real hospital records.** We don't have access to real
outpatient queue data for this project, so the queue-prediction model is trained on
generated scenarios instead, in place of it.

Generated by [`generate_synthetic.py`](generate_synthetic.py) (fixed random seed, fully
reproducible — run `python datasets/generate_synthetic.py` to regenerate it). The
generation logic:

- `current_queue_length` and `emergency_patients_ahead`: Poisson-distributed, modeling
  essentially-random patient arrivals.
- `average_consultation_minutes`: normally distributed around a typical appointment length.
- `actual_wait_minutes` (the training target): queue length + emergencies ahead, times
  consultation length, adjusted by a time-of-day effect (clinics tend to run behind
  schedule around midday) and a day-of-week effect (Monday absorbs weekend backlog;
  weekends are quieter), plus Gaussian noise scaled to the base wait — real clinics
  don't run exactly on schedule.

This should be stated explicitly in the graduation report as synthetic data used as a
stand-in for real hospital queue data, not presented as if it were real-world data.
